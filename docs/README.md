# OctoAcme Project Management Docs

Welcome to the OctoAcme project management process documentation. These guides provide a structured approach to planning, executing, and delivering projects with clarity, collaboration, and measurable outcomes.

## Process Overview

OctoAcme follows a lifecycle-driven approach to project management:

1. **Initiation** – Define the problem, stakeholders, and a high-level timeline.
2. **Planning** – Break work into shippable increments, estimate, and identify dependencies.
3. **Execution** – Build, test, review, and iterate in short cycles.
4. **Release** – Deploy to production, verify, and monitor.
5. **Retrospective** – Capture learnings and drive continuous improvement.

## Core Principles

- **Customer-first**: Prioritize customer value and usability.
- **Iterative delivery**: Deliver small, testable increments frequently.
- **Clear ownership**: Each project has a named Project Manager (PM) and Product Lead.
- **Data-informed**: Measure impact and iterate based on evidence.
- **Psychological safety**: Encourage feedback, experimentation, and learning.

## Quick Reference

### Communication Cadence
- Daily standups (15 min)
- Weekly PM + PdM sync
- Twice-weekly delivery team standups
- Monthly stakeholder updates

### Key Artifacts
- Project Charter / One-pager
- Risk Register
- Sprint/Iteration Backlog
- Acceptance Criteria & Definition of Done
- Retrospective notes and action items

## How to Use These Docs

- New team members should start with the Project Management Overview and Roles and Personas guides.
- For a new project, follow the lifecycle guides in order: Initiation → Planning → Execution → Release → Retrospective.
- Reference the Risk Management & Communication guide throughout the project lifecycle.
- Keep project charters and artifacts in your project repo for Copilot Spaces to use as context.
